接入真实制作机

NO PACKAGES

同一端口自动识别裸 FLV 流或 RTMP 推流。源重连后自动生成新代次，旧缓存隔离。

# 裸 FLV over TCP
ffmpeg -re -i match.mp4 -c copy -f flv tcp://127.0.0.1:1935

# 标准 RTMP 推流
ffmpeg -re -i match.mp4 -c copy -f flv rtmp://127.0.0.1/live/match

诊断口径

SEPARATED
  • 客户端慢服务端队列超过水位，丢媒体至下一关键帧；连接仍在线。
  • 网络断开浏览器 WebSocket 关闭或心跳超时，本机自动退避重连。
  • 源流没了源 TCP 断开，或 5 秒无媒体；观看端收到 source-timeout。
