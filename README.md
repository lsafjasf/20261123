# Relink Desk · 素材重连工作台

本机运行、零第三方依赖的剪辑素材重连工具。它不会修改工程时间线，只读取工程中的素材引用，在新盘里对同名文件做证据排序，并把确认后的结果写成独立的相对路径映射。

## 快速开始

要求 Node.js `>= 22.18`（使用内置 TypeScript 类型擦除）。

```bash
npm start
```

打开 `http://127.0.0.1:4173`。默认会自动载入 `sample/` 演示工程；想先看手动配置页，访问 `http://127.0.0.1:4173/?manual=1`。

```bash
npm test        # 匹配策略与 MP4 探针单元测试
npm run build   # 只把 src/client/*.ts 编译到 public/js
```

也可以直接启动：

```bash
node --experimental-strip-types server.ts
```

## 工作流

1. 指定工程文件。支持 FCPXML、Premiere XML（`xmeml`）、JSON 清单。
2. 指定新素材根目录，服务端递归扫描媒体文件并用 Node 标准库读取 MP4/MOV 轨道参数。
3. 可选指定旧盘参考目录。旧盘可读时，会流式计算 SHA-256，并在浏览器中提取短音频频谱指纹和画面指纹。
4. 对每个工程引用按文件名建组，使用以下证据排序：
   - 时长与媒体参数（尺寸、帧率、编码、声道、采样率）
   - 内容 SHA-256
   - WebAudio 短音频指纹
   - Canvas + WebCodecs 画面指纹
5. 只有证据充分才自动匹配。同名多候选、哈希冲突、证据不完整时进入人工确认。
6. 人工确认后保存映射。工程文件全程只读，时间线、剪辑点、特效和素材入出点不变。

## 保守匹配规则

- 参考哈希与候选哈希完全一致，且没有第二个同样匹配的候选：自动匹配。
- 唯一同名候选，且工程时长、尺寸与参数完全一致：自动匹配。
- 存在多个同名候选，但没有旧盘参考哈希/指纹：强制人工确认。
- 哈希冲突、时长明显不符、参数冲突：不自动匹配。
- 已人工确认后改选其他候选：会退回待确认状态，必须再次确认。

没有旧盘参考目录时，内容哈希和音频指纹仍会用于候选分析与展示，但没有“参考值”可比较，因此不能帮助排除同名手机视频。这是刻意设计的风险边界。

## 导出

点击“保存映射”后，文件写入 `exports/relink-<timestamp>/`：

- `relink-map.json`：映射主文件，包含证据、时间线引用 ID、工程哈希校验结果。
- `missing-files.csv`：仍然缺失的文件。
- `unresolved.csv`：尚未人工确认的项目，不会进入 mappings。
- `summary.md`：数量摘要与只读校验结果。

每个映射同时提供：

- `mediaRootRelative`：相对新素材根目录的 POSIX 路径。
- `projectRelative`：相对工程目录的 POSIX 路径，适合工程与素材一起迁移。
- `template`：`${MEDIA_ROOT}/...` 形式，可替换素材根目录后使用。

导出前服务端会再次计算工程 SHA-256；如果工程在分析后被外部修改，报告会标记 `projectUnchanged: false`。

## 技术约束

- TypeScript：客户端与 Node 服务均为 TypeScript 源码。
- Node.js 标准库：HTTP、文件扫描、流式哈希、MP4/MOV 容器探针、导出写入。
- WebCodecs：通过 `VideoFrame` 取帧后交给 Canvas。
- WebAudio：解码短音频段并计算频谱指纹。
- Canvas：缩略图与 dHash 画面指纹。
- MediaSource：候选预览的流式缓冲路径，不支持时降级为普通媒体 URL。
- 不使用 npm 第三方包、不连接云服务。服务仅绑定 `127.0.0.1`。

## 已知边界

- MP4/MOV 的轨道参数由内置探针读取；其他容器会降级给浏览器读取可用元数据。
- 超过 96 MB 的文件跳过全量 WebAudio 解码，避免占满内存；哈希和时长/参数匹配仍可用。
- 短音频和画面指纹要求旧盘参考素材可读；没有参考数据时不会伪造相似度。
- 本工具输出映射，不直接改写 FCPXML/XML。这样可以保证时间线内容绝对不变。

## 演示数据

`sample/project.fcpxml` 包含 7 条素材引用，覆盖：

- 4 条旧盘哈希、音频和画面完全一致的自动匹配。
- 1 条新盘没有同名文件的缺失项。
- 1 条同名但时长不符的待确认项。
- 1 条旧盘无参考、存在两个同名同参数候选的待确认项。
- `BROLL_0001.MP4` 使用 fragmented MP4，可直接验证 MediaSource 预览路径；渐进式 MOV 会自动回退直连。

素材均为 5–9 秒的本地测试片段，不包含真实办公内容。
