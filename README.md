# 纪录片采访去混响(interview de-reverb)

为空房间录制的采访人声压低混响尾音。**软增益谱处理**,不是门限:
词尾和停顿只被按比例压低,永远不会被切断。

- 纯 TypeScript,零第三方依赖,零云端调用
- DSP 核心在 Node(测试)与浏览器(UI)间共享
- 浏览器端使用原生 WebAudio(解码/播放)、Canvas(波形/频谱)、
  WebCodecs(Opus 编码)、MediaSource(流式播放)
- Node >= 22.13(利用内置 TypeScript 类型剥离,无需编译器)

## 算法

`src/dsp/dereverb.ts`,两个协作的逐频带检测器:

1. **尾音扩展器**:慢释放峰值跟踪。语音持续时幅度贴着峰值,不动作;
   直声停止后幅度跌出峰值包络,判定为混响尾音并按跌落深度比例压制。
2. **雾减器**:最小值跟踪估计稳态混响底(元音下方持续堆积的部分),
   按维纳式谱减去除,并由"湿度"门控保护干声;低频允许更深压制。

增益有三重保护:全局下限(默认 -18 dB,绝不静音)、时频双向平滑
(防音乐噪声)、高频保护(6 kHz 以上逐渐放松,防止声音发闷)。

## 使用

```sh
npm test          # 回归测试(Node 内置 test runner)
npm run build     # 类型剥离 -> public/
npm run demo      # 生成示例音频 public/demo-interview.wav
npm run serve     # http://localhost:8321
```

UI 功能:逐句强度滑杆与旁路、全局 A/B 旁路、原声/处理后/残余尾音
三种试听、残余尾音波形+频谱视图(确认词尾还在)、WAV 下载、
Opus/WebM 经 MediaSource 流式播放。

## 回归测试(test/dereverb.test.ts)

- **干声直通**:对数谱距离 < 2 dB、谱质心偏移 < 5%、电平变化 < 1.5 dB
- **人工混响**(指数衰减 IR):尾音压低 > 6 dB,处理后比湿信号更接近干声,
  谱质心不比输入更暗(没有做闷)
- **模拟真实房间**(早期反射 + 分频衰减 IR):T60 明显缩短,最小增益
  >= 下限(无门限),尾音区无长静音段(词尾保留),谱质心不变暗
- **逐句控制**:旁路区域与输入一致,处理区域尾音确实压低
- **残余信号**:残余 = 输入 - 输出(精确重构),残余在语音段远低于
  信号电平(人声没有被吃掉)

## 目录

- `src/dsp/` — FFT/STFT、去混响核心、WAV 编解码、合成素材、指标、分段
- `src/app/` — 浏览器 UI、处理 Worker、WebM 封装器
- `test/` — Node 回归测试
- `tools/` — 构建(类型剥离)、静态服务器、示例生成
