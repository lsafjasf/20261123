# Loudness Desk

交付级响度复核工作台。面向连续播放与长音频检查，同时给出瞬时、短期、整段响度，采样峰值与真峰值，以及广告段独立统计、逐秒数据和可定位的问题区间。

全部计算在本机完成：TypeScript + Node.js 标准库 + Canvas / WebCodecs 等浏览器原生接口，无第三方运行时依赖，无云端上传。

![工作台截图](artifacts/ui.png)

## 运行

要求 Node.js 24+（直接运行 TypeScript 源码与内置类型剥离）。

```bash
npm start
```

打开 `http://127.0.0.1:4173`。服务会先构建浏览器端 TypeScript，再启动静态服务器。页面默认自动载入 `artifacts/demo.wav`；也可以拖入或选择本地音频。

其他命令：

```bash
npm run build   # 将 src/**.ts 剥离类型并输出到 public/js
npm run check   # 响度内核自检：分块等价、示例音频、广告段与问题区间
npm run analyze -- artifacts/demo.wav --ads 30-45 --out artifacts/demo-review
```

## 复核口径

- 响度：ITU-R BS.1770-4 K 加权；Momentary 为 400 ms 窗口 / 100 ms hop，Short-term 为 3 s 窗口，Integrated 使用 -70 LUFS 绝对门控与 -10 LU 相对门控。
- 峰值：采样峰取原始离散样本；真峰值在每个声道上做 8× 多相插值，高于 BS.1770 的 4× 最低建议，滤波历史跨分块保留。
- 广告段：节目净响度剔除全部广告时间；每段广告独立门控，并参与广告/节目响度偏差检查。
- 问题区间：逐秒聚合真峰值、采样峰、瞬时响度突发与静音标记，连续秒合并为区间；整段偏差和广告偏差单独成条，点击即可定位播放。
- 长音频：WAV 按 512 KiB 对齐帧流式解码，只保留滤波器状态、100 ms 指标、波形包络和门控统计，不创建整段 PCM / AudioBuffer 数组。
- 状态：扫描暂停会保留 K 加权、真峰值历史和积分直方图；播放暂停/继续以媒体时间定位，不重置累计显示。

默认交付口径为 `-14 LUFS / -1 dBTP`，侧栏可切换播客 `-16 LUFS`、广播 `-23 LUFS`，也可直接修改目标、容差与峰值线。

## 输入与输出

流式分析支持：

- WAV：PCM 8/16/24/32-bit、32-bit Float，1–8 声道。
- AAC/ADTS：浏览器提供 WebCodecs AAC 解码器时启用（Chromium 的编解码支持取决于发行版本）；否则会明确提示。
- 播放使用浏览器原生媒体解码；分析结果不依赖播放是否开始。

页面内输出：

- 直播区：当前 M / S / 至播放头 I、当前秒采样峰/真峰值。
- 时间线：波形、M/S 曲线、广告覆盖、问题条带、播放头与广告框选。
- `逐秒数据`：分页表格，支持全部 / 含标记 / 广告段筛选。
- `问题区间`：严重/警告筛选、指标和详情、一键定位。
- `分段统计`：节目净响度与每段广告的独立统计。
- `导出 JSON` 与 `导出逐秒 CSV`，包含口径、分段、问题区间和完整逐秒数据。

命令行输出同样为 JSON + CSV；本仓库已生成示例：

- `artifacts/demo-review.json`
- `artifacts/demo-review.csv`

## 示例音频验证

`artifacts/demo.wav` 为 90 秒、48 kHz、16-bit 立体声。示例默认标注 30–45 秒为广告段。

当前内核结果：

| 指标 | 结果 |
| --- | --- |
| 整段 I | -13.36 LUFS |
| 节目净 I（30–45 s 广告剔除） | -13.40 LUFS |
| 广告段 I | -13.17 LUFS |
| 采样峰 | -2.16 dBFS |
| 真峰值 | +0.35 dBTP |
| 问题区间 | 1 个静音段 + 3 处峰值/响度突发，共 10 条 |

`npm run check` 还会用同一段合成信号验证：一次性输入与 9 个任意切块输入的 Integrated 和 True Peak 必须一致，以覆盖暂停/继续和分块边界上的状态保持。

## 目录

```text
src/shared/     流式 WAV/AAC、K 加权、门控、真峰值、报告与导出
src/web/        Worker 扫描、播放监测、Canvas 时间线、页面渲染
scripts/        构建、自检、CLI 与无依赖浏览器冒烟测试
server.ts       node:http 静态服务器（支持 Range）
public/         构建后的浏览器端与样式
artifacts/      示例音频、截图与示例复核输出
```

自动标记用于快速定位，不替代主观监听。广告边界应以实际编排为准；平台规范与峰值上限可在侧栏调整。
