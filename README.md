# 录音剪接取证分析（splice-forensics）

本地、零第三方依赖的访谈录音剪接检测工具。技术组合：TypeScript + Node.js 标准库
（`node:http` 静态服务 + `node:module.stripTypeScriptTypes` 按需转译）+ 浏览器端
WebAudio / WebCodecs / Canvas / MediaSource。

## 运行

```bash
npm start          # 默认 8080，PORT=8787 npm start 可改端口
# 打开 http://localhost:8080 ，选择录音文件
npm test           # 合成样本回归测试（拼接点检出 + 良性事件抑制）
```

## 分析通道（全部基于原始 PCM，不做降噪，证据不被抹除）

- **房间底噪阶跃**：幅度谱 20% 分位估计底噪电平，比较切点前后 0.5s 窗中位数差。
  同一房间连续录音底噪应近似平稳；拼接另一段（即使同一房间、不同时间/设备增益）会产生阶跃。
- **相位连续性**：相位声码器偏差（实测相位推进 vs 线性预期），按幅度加权。
  拼接点处大量频带同时失锁。
- **样本连续性**：原始 PCM 一阶差分局部峰值 + 直流偏置阶跃，捕捉硬切口的采样级跳变。
- **短时重复**：低能帧底噪谱指纹两两相关（间隔 >2s），接近 1.0 的相关说明
  底噪床被复制粘贴（自然底噪不会逐帧重合）。

## 判定规则（防误报）

- 各通道用中位数 + MAD 的稳健 z 分数，灵敏度滑块映射阈值（z 2.5–7）。
- 默认要求 **≥2 项独立证据**同时超阈才判定可疑；衣料摩擦/爆音只触发样本跳变
  单通道，会被抑制；换气/停顿只改变能量、底噪与相位保持连续，标注为良性事件而非篡改。
- 证据图（Canvas）：波形包络 + 四条特征曲线 + 阈值线 + 可疑边界竖线，可导出 PNG。
- 点击结果表 ▶ 通过 MediaSource 循环试听切点 ±2s 片段。

## 解码

WebAudio `decodeAudioData` 优先；失败回退手工 WAV 解析（PCM 8/16/24/32 与 float32），
ADTS AAC 走 WebCodecs `AudioDecoder`。文件不离开本机。
