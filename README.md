# 双领夹麦串音处理工具

双人访谈两支领夹麦互相串音（对方的声音漏进本麦），切机位后音量跳变。
本工具对两支**时间对齐**的单声道轨做**软衰减去串音**，并解决电平不一致问题。

## 设计要点

- **非破坏性**：原始录音永不修改，处理在内存中进行，导出为新 WAV 文件。
- **软衰减而非噪声门**：最大衰减深度受限（默认 14 dB）、30ms 攻击 / 250ms 释放 /
  120ms 保持 / 120ms 介入延时，增益曲线全程平滑，避免"门限机器音"。
- **保护自然重叠与笑声**：只有包络能被"对方信号 × 串音比"完全解释时才衰减；
  本人包络高于串音预测底线（重叠讲话、大笑）时立即快速恢复（60ms），不衰减。
- **电平匹配**：两轨活动段 RMS 拉齐（限幅 ±8 dB），缓解切机位后的音量跳变。
- **可视化**：波形上红色区域标出被衰减时段（透明度随深度），底部红色曲线为增益；
  衰减段列表可点击定位；每支麦可**单独旁路**（播放与导出均回退到原录音）。

## 使用

```bash
npm install        # 仅安装 TypeScript（devDependency）
npm run demo       # 可选：生成 demo_micA.wav / demo_micB.wav 演示录音
npm run serve      # 编译并启动静态服务器
# 打开 http://localhost:8080/ ，分别选择麦 A、麦 B 的录音，点击"开始处理"
```

媒体侧只用浏览器 WebAudio（解码/播放）、Canvas（可视化）、标准 WAV 编码导出；
不安装任何运行时第三方包，不调用云服务。

## 回归测试

```bash
npm test
```

程序合成"合唱式"重叠双人语音（`src/dsp/synth.ts`：谐波+共振峰音节、
抢话重叠、同时大笑，串音 -8/-14 dB、1.2ms 延时，3 个种子 × 2 种串音电平），
对每轨检查：

| 指标 | 门限 | 含义 |
| --- | --- | --- |
| 错误衰减率 | < 5% | 本人发声（含笑声）时被衰减超 3dB 的帧占比 |
| 重叠段误衰减 | < 2% | 双方同时发声时被衰减超 3dB 的帧占比 |
| 残留串音抑制 | ≥ 6dB | 本人静音、对方发声段的串音残余（实测 6~8.6dB） |
| 增益平滑度 | < 5dB/帧 | 无门限式瞬时跳变 |
| WAV 往返 | < 1e-3 | 16bit 编解码精度 |

## 结构

```
src/dsp/debleed.ts   去串音核心（浏览器与 Node 共用，纯 TS + Float32Array）
src/dsp/wav.ts       WAV 编解码（8/16/24/32 位整型、32 位浮点）
src/dsp/synth.ts     合唱式重叠语音合成器（确定性种子）
src/node/regression.ts  回归测试
src/node/serve.ts    零依赖静态服务器
src/web/app.ts       浏览器 UI（WebAudio + Canvas）
index.html           页面
```
