# 镜头暗角平场校正（vignette-corrector）

同一支定焦镜头拍出的视频四角总比中心暗，且换机位后暗角深浅不同。本工具用
平场素材估计二维增益图，对每段视频做可调校正：保留画面真实渐变、避免高光
溢出，同一映射应用到不同分辨率时改善一致。完全离线，零第三方依赖。

## 运行

```sh
npm run build    # 用 Node 内置类型擦除把 src/*.ts 编译到 public/js/
npm run serve    # 纯 Node 标准库静态服务器，默认 http://localhost:8080
npm test         # 核心算法单元测试（Node 内置 test runner）
npm run smoke    # 端到端冒烟测试（需要本机 Chrome，可用 CHROME= 指定路径）
```

`PORT=9000 npm run serve` 可换端口。构建与运行均不需要安装任何 npm 包。

## 使用流程

1. **平场素材**：载入对均匀目标（白墙/灰卡，失焦）拍摄的视频，手动采集
   若干帧或「自动采样」，然后「估计增益图」。映射可导出为 JSON 复用。
2. **待校正视频**：可一次载入多段；每段视频的强度/高光保护/拐点/锁定色彩
   参数独立保存，切换视频自动恢复——对应换机位后暗角深浅不同的情况。
3. **预览**：原图 / 校正 / 分屏（可拖动分界）/ 增益图，快捷键 1/2/3/4，
   空格播放暂停。下方表格实时给出四角与中心采样（校正前后亮度与
   角落/中心比值）。
4. **输出**：导出全分辨率校正帧 PNG；或录制校正视频（canvas.captureStream
   + MediaRecorder，监视窗通过 MediaSource 实时回放）。

## 技术要点

- **增益模型**：64×36 网格存于归一化坐标，双线性采样 + 边缘线性外插。
  任何分辨率采样同一连续曲面，因此跨分辨率改善一致（有单测覆盖）。
- **平场估计**：多帧平均 → 块平均降采样到网格 → 3×3 平滑 → 以最亮四分位
  为参考电平取倒数，增益钳制到 `maxGain` 以限制暗角噪声放大。
- **渐变保留**：校正为低频乘性增益，中心增益归一约为 1，只去除镜头
  渐晕，不抹平场景本身的明暗渐变（有单测覆盖）。
- **高光保护**：拐点以下恒等，以上指数肩部软压缩渐近 255，单调不溢出；
  强度滑杆在恒等与完全校正间插值（可过冲到 150%）。
- **锁定色彩**：默认三通道共用亮度增益，避免角落色偏；可关闭做逐通道校正。

## 目录

- `src/` TypeScript 源码（仅可擦除语法，Node 24 直接构建）
- `public/` 页面与构建产物（`public/js/` 由 `npm run build` 生成）
- `test/` 核心算法单元测试（跑在构建产物上）
- `scripts/smoke.mjs` CDP 驱动的真实浏览器端到端测试
- `server.mjs` / `build.mjs` 纯 Node 标准库
