# 气口守门人 · Breath Gate Studio

有声书呼吸编辑工作台。它不会把所有吸气声一刀切掉，而是把事件分成三类，默认采用不同策略：

- **可清理气口**：短、干、远离语句，默认缩短。
- **情绪呼吸**：长、偏响、贴近语句或带声带成分，默认保留。
- **低频冲激**：喷麦、爆音和短促低频瞬态，默认只降低 12 dB，避免破坏邻近字音。

每个事件都可以手动改类，并选择恢复原声、缩短、淡出或降低。缩短会产生真实时间轴裁切；淡出保持时长；恢复与保留都逐样本还原。所有剪切和淡出接缝从最近的安静窗提取真实房间底噪，再按局部底噪电平匹配填充。

## 运行

```bash
npm start
# 打开 http://127.0.0.1:4173
```

`npm start` 会生成可重复的 18 秒测试段落、用 Node 内置 TypeScript 类型剥离构建浏览器模块，并启动零依赖静态服务器。

```bash
npm test                          # DSP、编辑、WAV 和审计清单测试
npm run smoke                     # 另开终端保持 npm start 时，跑无头 Chromium 端到端导出
```

无第三方运行时或开发依赖，不接入云服务。

## 工作流

1. 拖入本地音频，或使用自动载入的测试段落。
2. 在波形中查看三类事件，点击事件进入右侧检查器。
3. 调整分类、处理动作和“缩短保留量”。分类可随时覆盖，备注会保留。
4. 用“原始 / 处理后”切换监听。处理后时间轴会按缩短后的真实长度播放。
5. 打开“导出与核验”，生成 32-bit float WAV 和逐样本清单。

## 判定方式

分析在浏览器内存中完成，使用 1024 点 FFT、约 5.8 ms 帧移，并计算：

- RMS、峰值、峰均比
- 低频 / 语音频段 / 高频能量占比
- 频谱平坦度（噪声样程度）
- 过零率与频谱质心
- 事件与最近语音段的时间距离

保守度滑块会改变“情绪呼吸”阈值。重新分析时，按时间重叠把已有手动分类、处理、备注映射到新事件，不会覆盖审听决定。

这是可解释的启发式模型，不依赖机器学习。真正暧昧的表演呼吸应由审听者最后确认。

## 样本审计

导出旁的 `*.manifest.json` 记录：

- 每个事件的源样本范围、输出样本范围、动作、移除量和留档备注
- 每个接缝的输出范围、底噪来源范围、局部底噪与接缝电平
- 所有逐样本未改动的映射段
- 输入输出格式、SHA-256、峰值和总改动量

单位约定：`*StartSample` / `*EndSample` 是每声道时间轴索引；`*Frames` 是每声道时间轴帧数；`*Samples` 是跨所有声道的样本值数量。

## 导出核验

导出后重新解码 WAV，并逐项核对：

- 输出总时长与渲染长度一致
- 峰值与渲染结果一致且无削波
- 每个未处理映射段逐样本一致，记录最大差值
- WebCodecs `AudioData` 独立读取帧数与峰值指纹

任何一项失败都会在对话框中明确标红，不会默默通过。

## 架构

```text
src/analyzer.ts   分帧、房间窗、三类事件判定
src/editor.ts     时间轴裁切、淡出、底噪接缝、样本映射
src/dsp.ts        FFT、特征、WAV float32 编解码辅助
src/audio.ts      WebAudio 解码/播放、WebCodecs 指纹、导出核验
src/waveform.ts   Canvas 原始/处理后双轨与事件层
src/manifest.ts   审计 JSON
src/app.ts        工作台状态与交互
scripts/          Node 标准库构建、演示音频、浏览器烟雾测试
```

WebAudio 负责低延迟试听，WebCodecs 用于独立 PCM 指纹，Canvas 绘制波形，MediaSource 能力会在界面状态栏探测显示；母版导出采用无损 WAV，避免为了预览容器引入额外转码。
