# 多段母带动态实验室

离线多段母带处理工具：分频 → 每段独立动态（可调瞬态保留）→ 响度归一 →
前瞻砖墙限制器，全程可视化每段增益变化、短时能量与峰值，峰值绝不越过天花板。

## 运行

```sh
node build.mjs     # TypeScript 类型擦除 -> public/js（Node 内置能力，零依赖）
node server.mjs    # 打开 http://localhost:8080
node test/run.mjs  # 无头对照测试（鼓点 / 扫频 / 持续低频）
```

零第三方包：DSP 与界面仅用 TypeScript + Web 标准 API（WebAudio 解码/播放、
Canvas 可视化），构建与测试仅用 Node.js 标准库，全部离线可用。

## 信号流

1. **分频**：LR4（四阶 Linkwitz-Riley）级联分频，默认 150 / 1200 / 5000 Hz，
   四段全通求和（幅度平坦，最大偏差 < 0.75 dB）。
2. **每段压缩**：峰值包络检测 + 软膝静态曲线 + 启动/释放平滑；
   「瞬态保留」根据快/慢包络波峰差在瞬态期间回退增益衰减；
   「最大GR」硬上限防止过度压缩。
3. **响度归一**：BS.1770 K 加权 + 门控积分响度；补偿增益受
   `min(最大补偿, 天花板 − 峰值 + 限制器GR预算)` 约束——宁可达不到响度目标，
   也不把总线压扁。
4. **限制器**：1.5 ms 前瞻砖墙限制器（滑动窗最大值 + 释放平滑），
   输出峰值数学上不超过天花板。
5. **分析**：每段短时能量（50 ms RMS）与峰值、积分/短时/LRA 响度、
   4× 过采样真峰值、逐瞬态冲击损失（起音后 15 ms RMS 差）与波峰因数变化。

## 界面

- 波形视图：原始（灰）/处理后（蓝）叠加，红色虚线为峰值天花板。
- 增益泳道：四个频段 + 限制器的逐样本增益变化（dB）。
- 能量泳道：每段短时能量曲线与峰值标记。
- 导出：24-bit WAV、响度统计 JSON、瞬态损失报告 JSON。
